# 계약 등록·수정 팝업 UX 설계 시나리오 (모바일 우선)

> 1인 관리자가 스마트폰·태블릿에서도 창고 현황을 한눈에 파악하고 컨테이너 위치를 손끝으로 지정할 수 있게 하는,
> **하나의 통일된 계약 팝업 템플릿** 설계서. 기술 스택·코드·파라미터명은 배제하고 화면 구조와 인터랙션 로직만 다룬다.

---

## 0. 설계 원칙 (전체를 관통하는 5가지)

1. **하나의 템플릿, 두 개의 모드** — 등록/수정은 별도 화면이 아니라 `mode` 값만 다른 동일 템플릿. 관리자는 항상 같은 위치에서 같은 정보를 본다.
2. **"위치 지정"은 텍스트가 아니라 지도** — A-01 같은 코드 목록 대신, 창고를 눈으로 보고 빈칸을 터치한다.
3. **위치는 필수가 아니다** — 미지정을 1급 시민으로 취급. 지정하지 않아도 계약은 성립한다.
4. **모바일 엄지 우선** — 핵심 액션은 화면 하단, 지도는 확대/스크롤 가능, 터치 타깃은 충분히 크게.
5. **되돌릴 수 있는 안전함** — 수정 모드에서 원래 위치를 항상 기억하고, 언제든 "원상 복구"로 돌아갈 수 있다.

---

## 1. 통일된 등록/수정 팝업 레이아웃 구조

### 1.1 전체 골격 — "위→아래 3영역 + 고정 푸터"

모바일에서는 세로 스택, 태블릿/데스크톱에서는 좌우 2열로 자연스럽게 펼쳐지는 **단일 스크롤 시트(Sheet)** 구조를 기본으로 한다.

```
┌───────────────────────────────┐
│ [헤더]  계약 등록 / 계약 수정   [✕] │  ← 모드에 따라 타이틀만 바뀜
├───────────────────────────────┤
│ ① 계약 기본 정보 영역           │  ← 고객/기간/보관료 등
│                               │
│ ② 컨테이너 위치 지정 영역 ★     │  ← 이 설계의 핵심
│                               │
│ ③ 메모/특이사항 영역           │
├───────────────────────────────┤
│ [고정 푸터]   취소     저장/등록 │  ← 스크롤과 무관하게 항상 하단 고정
└───────────────────────────────┘
```

- **①·③은 접이식(Accordion) 후보**: 화면이 좁을 때 위치 지정에 집중하도록, 기본 정보와 메모는 "요약 한 줄 + 펼치기"로 접어둘 수 있게 한다. 위치 지정 영역만은 항상 펼쳐진 상태를 기본으로.
- **고정 푸터**: 지도를 스크롤하다 손을 떼지 않고도 저장할 수 있도록 저장/취소 버튼은 시트 하단에 sticky로 고정. 저장 버튼에는 현재 선택 상태를 한 줄 요약(예: "A-01 지정 · 저장").

### 1.2 반응형 배치

| 화면 | 레이아웃 | 위치 지정 영역 |
|---|---|---|
| 폰(세로) | 1열 세로 스택 | 전체 폭. 지도는 가로 스크롤 + 핀치 줌 |
| 태블릿/데스크톱 | 좌: 폼(기본정보·메모) / 우: 위치 지정 지도 | 우측 고정 폭 패널, 세로로 넉넉히 |

핵심은 **"컨테이너 위치 지정 영역이 폼 흐름의 한가운데(②)에 온다"** 는 것. 위치는 계약의 부속이 아니라 관리자가 가장 신경 쓰는 결정이므로, 스크롤을 내리다 자연스럽게 만나되 맨 밑(묻히는 자리)에 두지 않는다.

### 1.3 위치 지정 영역의 내부 구조 (항상 3층)

```
② 컨테이너 위치 지정
 ┌ (a) 상태 바 : 현재 선택 요약 + [미지정] 토글 ┐
 │ (b) 구역/창고 선택 : A동 · B동 · 야적장 탭     │
 │ (c) 시각 맵(격자) : 빈칸/사용중 색상, 터치 선택 │
 └──────────────────────────────────────────────┘
```

- (a) 상태 바: "선택됨: **A-01**" 또는 "위치 미지정" 을 큼직하게. 오른쪽엔 미지정 토글(§3).
- (b) 구역 탭: 창고가 여러 동/구역이면 상단 가로 탭으로 전환. 각 탭에 "빈칸 12 / 전체 40" 같은 여유 현황을 숫자로 병기.
- (c) 격자 맵: 실제 선택이 일어나는 곳(§2).

## 2. 컨테이너 위치 시각 컴포넌트 & 인터랙션

### 2.1 시각 모델 — "창고를 위에서 내려다본 격자 지도"

컨테이너 자리를 **격자(Grid) 칸**으로 그린다. 한 칸 = 한 슬롯(자리). 칸은 창고의 실제 배열(가로 열 × 세로 행)을 그대로 반영해, 관리자가 "왼쪽 아래 구석 그 자리"를 눈으로 찾을 수 있게 한다.

- **구역(A동/B동)** → 상단 탭
- **행·열** → 격자의 좌표
- **다단 적재(층)** → 한 칸을 눌렀을 때 층(1층/2층/3층)을 고르는 하위 선택으로 분기 (또는 칸 안에 작은 층 인디케이터)

### 2.2 칸의 상태와 색상 (한눈에 읽히는 범례)

| 상태 | 색/형태 | 터치 시 |
|---|---|---|
| 빈 자리 | 옅은 회색 점선 테두리 | **선택 가능** — 누르면 이 계약의 자리로 지정 |
| 사용 중(타 계약) | 진한 채움 + 화주명 축약 | 선택 불가(비활성). 길게 누르면 누가 쓰는지 툴팁 |
| 내가 선택한 자리 | 브랜드색 채움 + 체크 | 다시 누르면 선택 해제 |
| 점검/불가 | 빗금 패턴 | 선택 불가 |

색만으로 구분하지 않고 **아이콘·패턴·테두리**를 함께 써서 색약 사용자도 구분되게 한다(접근성).

### 2.3 인터랙션 흐름

1. **탭으로 구역 선택** → 해당 구역 격자가 그려진다.
2. **빈 칸을 터치** → 즉시 그 칸이 "내 선택"으로 강조되고, 상단 상태 바가 "선택됨: A-01"로 갱신. (한 번의 터치로 선택 완료 — 확인 버튼 불필요)
3. **다른 빈 칸을 터치** → 이전 선택은 자동 해제되고 새 칸으로 이동(단일 선택 원칙). 이동 시 짧은 애니메이션으로 "선택이 옮겨갔다"를 보여준다.
4. **선택한 칸을 다시 터치** → 선택 해제 → 자동으로 "미지정" 상태로 전환.

### 2.4 모바일 조작 편의 장치

- **핀치 줌 & 팬**: 격자가 많으면 두 손가락으로 확대, 한 손가락으로 이동.
- **미니맵/현재 위치 표시**: 확대 상태에서 지금 화면이 창고 어디쯤인지 작은 인디케이터로 안내(길 잃음 방지).
- **빈자리 바로가기**: "가장 가까운 빈자리로 이동" 또는 "빈자리만 보기" 필터 토글. 사용 중 칸을 흐리게 처리해 빈칸이 튀어 보이게 한다.
- **검색으로 점프**: 자리 코드(A-01)나 화주명을 입력하면 해당 칸으로 지도가 스크롤·하이라이트. 시각 선택을 못 하는 상황의 보조 수단.
- **충분한 터치 타깃**: 칸 사이 여백을 확보해 오터치를 막고, 확대하지 않아도 누를 수 있는 최소 크기를 보장.

## 3. 컨테이너 '미지정' 선택 시 UX 가이드

### 3.1 미지정을 눈에 띄는 1급 옵션으로

위치 지정 영역 상태 바(2.1-a) 우측에 **"위치 미지정" 토글**을 상시 노출한다. 텍스트는 "나중에 지정" 정도로 부드럽게. 이 토글은 두 방향으로 작동한다.

- **토글 ON(미지정)** → 격자 맵이 흐려지고 상호작용이 잠긴다(비활성 오버레이 + "추후 지정 예정" 안내 문구). 기존에 고른 칸이 있었다면 선택이 해제된다.
- **격자에서 빈칸을 직접 터치** → 토글은 자동으로 OFF로 풀리고, 그 칸이 선택된다. (즉, 지도 선택과 미지정 토글은 상호 배타적으로 자동 동기화)

### 3.2 미지정 상태의 화면 반응

- 상태 바 문구가 "**위치 미지정**"으로 바뀌고, 색은 중립(회색)으로.
- 저장 버튼 라벨에 상태를 반영: "미지정으로 등록".
- 저장은 정상 허용 — **위치는 필수값이 아니다.** 다만 저장 직전 가벼운 확인 문구(비차단형 배너)로 "위치를 지정하지 않고 등록합니다. 이후 언제든 지정할 수 있어요."를 안내해, 실수로 빈 채 넘어간 게 아님을 확인시킨다.

### 3.3 미지정 계약의 이후 여정(폐루프 설계)

- 미지정으로 저장된 계약은 목록에서 **"위치: 미지정" 뱃지**로 구분되어, 나중에 지정해야 할 대상이 한눈에 모인다.
- 목록/상세에서 "위치 지정" 바로가기를 제공해 같은 격자 지도로 재진입 → 자리를 고르고 저장하면 미지정이 해소된다.
- (권장) 대시보드에 "위치 미지정 N건" 지표를 두어, 1인 관리자가 놓치지 않게 상기시킨다.

## 4. 등록 모드 ↔ 수정 모드: UI 전환과 기존 데이터 시각화

### 4.1 같은 템플릿, `mode`만 다르다

| 요소 | 등록 모드 | 수정 모드 |
|---|---|---|
| 타이틀/저장 버튼 | "계약 등록" | "계약 수정 · 저장" |
| 기본 정보 필드 | 빈 상태에서 입력 | 기존 값으로 채워진 상태 |
| 격자 지도 | 선택 없음(빈 상태) | **기존 자리가 이미 강조되어 표시** |
| 미지정 토글 | 기본 OFF(또는 정책상 선택) | 기존이 미지정이면 ON으로 시작 |

레이아웃·컴포넌트·색상 규칙은 동일. 관리자는 "등록이든 수정이든 같은 화면"이라는 안정감을 얻는다.

### 4.2 수정 모드에서 기존 위치를 표현하는 전략

- **진입 즉시 기존 자리로 지도 포커스**: 수정 창을 열면 해당 계약이 쓰던 구역 탭이 자동 선택되고, 지도가 그 칸으로 스크롤·확대되어 **"현재 여기예요"** 를 강조한다(펄스/굵은 테두리).
- **"현재 위치" vs "변경 후 위치" 이중 상태**: 원래 자리는 은은한 기준 마커(예: 점선 고리)로 계속 표시하고, 관리자가 새 칸을 고르면 새 칸이 브랜드색으로 강조된다. 두 칸이 동시에 보여 **"어디서 어디로 옮기는지"** 가 시각적으로 드러난다.
- **변경 요약 배너**: 자리를 바꾸면 상단에 "A-01 → B-03 으로 이동" 같은 변경 diff를 한 줄로 보여준다. 바꾸지 않으면 배너는 나타나지 않는다.
- **원상 복구**: 변경 요약 배너 옆에 "되돌리기"를 두어, 잘못 건드렸을 때 원래 자리로 즉시 복귀.

### 4.3 수정 시 주의 상태의 처리

- **이미 다른 계약이 점유한 칸**은 수정 모드에서도 당연히 비활성. 이동하려면 그 칸이 비어 있어야 함을 색·툴팁으로 알린다.
- **위치 → 미지정으로 되돌리는 경우**: 미지정 토글을 켜면 "현재 A-01에서 위치를 해제합니다"를 확인 배너로 안내(비차단형). 실수 방지.
- **활성/비활성 규칙**: 계약이 이미 출고 완료 등 잠겨야 하는 상태라면, 위치 지정 영역 전체를 읽기 전용(기존 자리만 표시, 선택 불가)으로 낮춰 오조작을 막는다. — 같은 템플릿에서 `mode`와 계약 상태에 따라 컴포넌트 활성도만 동적으로 조절.

## 5. 부록 — 완성도를 높이는 디테일

- **상태 범례 상시 노출**: 지도 하단에 "■ 사용중 · ▢ 빈자리 · ✔ 선택 · ▨ 점검" 미니 범례를 고정해, 처음 보는 사람도 색을 해석할 수 있게.
- **빈 창고/구역 없음 예외**: 등록 가능한 자리가 하나도 없으면 지도 대신 "빈 자리가 없습니다 — 미지정으로 등록하거나 구역을 추가하세요" 안내 + 미지정 경로로 유도.
- **낙관적 피드백 + 충돌 방지**: 선택은 즉시 반영하되, 저장 시점에 그 자리가 이미 다른 계약에 선점됐다면(동시 편집) "방금 A-01이 사용됨 — 다른 자리를 선택하세요"로 자리만 초기화하고 나머지 입력은 보존.
- **검증·에러는 필드 옆에서**: 저장 실패 시 팝업 상단에 몰아 보여주지 말고, 문제 필드(기간 역전, 보관료 누락 등) 바로 아래에 인라인으로. 위치 관련 문제는 지도 위에 오버레이 문구로.
- **접근성**: 색+아이콘 이중 인코딩, 지도 대체 수단으로 코드/화주 검색 제공, 터치 타깃 최소 크기 보장, 키보드/스크린리더 사용 시 "구역→행→열→층" 순의 논리적 포커스 이동.

## 6. 한 줄 요약

**"같은 팝업 안에서, 창고를 지도로 보여주고, 빈칸을 눌러 자리를 정하되, 굳이 안 정해도 되고(미지정), 수정할 땐 원래 자리를 강조해 어디서 어디로 옮기는지 눈에 보이게 한다."** — 이것이 1인 관리자가 창고 안에서 길을 잃지 않게 하는 핵심이다.
